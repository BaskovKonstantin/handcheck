# Презентация для жюри ФСП 2026

Официальный шаблон ФСП, 20 слайдов. Сборка детерминированная: правится скрипт, а не файл
в PowerPoint, — иначе следующая сборка затрёт правки.

| Файл | Что это |
|---|---|
| `docs/presentation/HandCheck-ФСП-2026.pptx` | сдаваемый файл |
| `docs/presentation/HandCheck-ФСП-2026.pdf` | та же дека в PDF (собирается автоматически) |
| `docs/presentation/template-fsp-2026.pptx` | шаблон ФСП из вложения организаторов, 37 слайдов |
| `scripts/build-jury-deck.py` | сборщик: текст, графики, скриншоты, заметки докладчика |
| `https://handcheck.baski.pro/downloads/HandCheck-FSP-2026-presentation.pdf` | публичная ссылка для формы сдачи |

## Как пересобрать

```bash
~/.venvs/pptx/bin/python scripts/build-jury-deck.py       # python-pptx + Pillow
```

Скрипт берёт числа из `context/metrics-assessment.json`, скриншоты — из
`handcheck-ui/presentation/`, правит слайды 7–11 шаблона (обязательные), добавляет
15 своих слайдов, собирает PDF через LibreOffice и копирует оба файла в
`app/public/downloads/`.

## Структура дека

| № | Слайд | Что доказывает |
|---|---|---|
| 1 | Титульный | название и одна фраза о сути |
| 2 | О команде | суть решения и уникальность, баннер команды |
| 3 | Команда | состав и роли (карточки лишних участников удалены — так требуют правила ФСП) |
| 4 | Краткая история | почему задача, что было сложно, как проверяли себя |
| 5 | Коротко о решении | техническая и маркетинговая суть |
| 6 | Как это работает | четыре шага механики |
| 7 | Почему резюме не работает | проблема |
| 8 | Кабинет работодателя | **скриншот колоды** с подписью: категория и объяснение, контактов нет |
| 9 | Работодатель: подборка и приглашения | **два скриншота**: список совпадений и исходящие приглашения со статусами |
| 10 | Сквозной сценарий | пять шагов демонстрации |
| 11 | Тест, устойчивый к утечкам | банк, формы A/B, cutoff, дедлайны и кулдаун |
| 12 | Обратная механика подбора | категория → подборка → приглашение |
| 13 | Приватность как механика | 152-ФЗ, контакты, роли, токены |
| 14 | Кабинет кандидата | **три скриншота**: статус, приглашение с вилкой, батарея с таймером |
| 15 | Вход и мобильная версия | **два скриншота**: экран входа и кабинет на 390 px |
| 16 | Архитектура | компоненты и стек |
| 17 | Валидация теста | график score против cutoff, KPI процедуры |
| 18 | Что проверяется автоматически | 41 проверка аудита по блокам |
| 19 | Покрытие ТЗ | 40 пунктов проверено, 2 желательных, 3 концепции |
| 20 | Итог | что работает, ограничения, ссылки |

Каждый слайд имеет заметки докладчика (в PowerPoint — режим докладчика): что говорить
и на что обратить внимание. Под каждым скриншотом — подпись с пояснением, что на нём видно.

## Соответствие правилам организаторов

- Слайды 1–5 дека — это слайды 7–11 шаблона. Сетка, размеры блоков и базовое
  форматирование не тронуты: программная проверка геометрии (`scripts/build-jury-deck.py`,
  `fill_team_slide` / `set_lines`) меняет только текст. Исключения по правилам ФСП:
  - слайд 2 — пустой плейсхолдер «фото команды» заменён баннером той же геометрии;
  - слайд 3 — удалены четыре лишние карточки участников, оставшаяся карточка сдвинута
    в центр (размер и стиль блока не изменились).
- Служебные подписи «Образец текста» вычищены из макетов (80 штук).
- Числа на слайдах 17–19 берутся из измерений, а не из впечатлений:
  `context/metrics-assessment.json`, `context/audits/`, `docs/FUNCTIONAL-COVERAGE.md`.

## Что вписать перед сдачей

В деке осталось два поля, которые нельзя вывести из репозитория. В сборщике это
словарь `TEAM` и переменная `CITY` в начале файла:

| Поле | Где в деке | Как заполнить |
|---|---|---|
| телефон капитана | слайд 2 и слайд 3, строка «Телефон» | `TEAM[0]["phone"]` |
| город и регион | слайд 2, строка «Город и регион» | `CITY` |

Оба помечены в тексте как `‹вписать›` — найти их можно поиском по слову «вписать».

Если команда больше одного человека: допишите словарь в `TEAM` и пересоберите —
карточки создадутся сами, лишние удалятся, баннер на слайде 2 перерисуется.

# Короткая публичная презентация

`docs/presentation/HandCheck-overview.pptx` / `.pdf` — 13 слайдов: обязательные слайды
7–11 шаблона ФСП в исходном дизайне плюс восемь слайдов HandCheck в рекомендательной
зоне (концепция и архитектура, технологии, два слайда «Пример работы» со скриншотами
кабинетов, сценарий, приватность, валидация, итог).

| Файл | Что это |
|---|---|
| `docs/presentation/HandCheck-overview.pptx` | файл презентации |
| `docs/presentation/HandCheck-overview.pdf` | та же дека в PDF (собирается автоматически) |
| `scripts/build-overview-deck.py` | сборщик; хелперы берёт из `build-jury-deck.py` |
| `https://handcheck.baski.pro/downloads/HandCheck-overview.pdf` | публичная ссылка |

```bash
~/.venvs/pptx/bin/python scripts/build-overview-deck.py
```

Венв `python-pptx` переехал из `/tmp/pptxenv` в `~/.venvs/pptx`: старый путь стирался
при перезагрузке, и оба сборщика переставали запускаться.

Поля `‹вписать›` (телефон, город) — те же, что и в жюри-деке: см. раздел выше.
