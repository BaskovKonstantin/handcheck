Документ отвечает на вопрос «весь ли функционал ТЗ реализован» и на что опирается
каждое утверждение. Источник требований — [docs/TZ.md](./TZ.md).

## Как проверялось

Два независимых прогона [scripts/functional-audit.js](../scripts/functional-audit.js):

```bash
# полный (пишущий) прогон на чистой БД
PORT=8899 DB_PATH=/tmp/hc-audit.sqlite DEMO_MODE=1 npm start &
BASE_URL=http://127.0.0.1:8899 node scripts/functional-audit.js

# читающий прогон по проду (ничего не пишет в jury-БД)
BASE_URL=https://handcheck.baski.pro AUDIT_MODE=readonly node scripts/functional-audit.js
```

Плюс алгоритмические проверки качества теста и подбора:

```bash
npm run validate   # validate:assessment + validate:matching + validate:privacy
npm test           # 347 pass / 9 fail — те же 9 падений есть на чистом HEAD
```
